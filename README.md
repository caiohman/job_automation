# JOB AUTOMATION

pt-Br

O projeto visa a criação de uma automação completa do recebimento de contas a pagar e inserção dos dados no SAP. 

Os dados são provenientes do site SIDOM.

Para executar:

- Primeiro, instale as dependências com o seguinte comando:

`pip install -r requirements.txt`

- Segundo, execute o arquivo main.py:

`python main.py`

Para maiores informações consultar a pasta doc.
